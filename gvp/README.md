# GVP implementation

The files in this directory are based on the public GVP-GNN implementation used
for structure-conditioned protein representation learning. The original project
is referenced inside the code (for example, `gvp/data.py` points to the
`jingraham/neurips19-graph-protein-design` repository).

The GeoCDL preprocessing scripts use `gvp.models.CPDModel` as the pretrained
GVP encoder. Please keep the original attribution when redistributing or
modifying these files.
